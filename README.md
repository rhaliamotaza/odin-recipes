# Odin Recipes

Odin Recipes is a basic recipe websitre created as part of The Odin Project Foundations course. The website contains a main page that links to several recipe pages, with each recipe containing an image, description, ingredients, and steps.

By completing this project, I will demonstrate my understanding of basic HTML concepts, including creating HTML boilerplate, using headings, paragraphs, images, links, unordered lists, and ordered lists. I will also practice organizing files and directories, using relative paths, and using Git and GitHub to manage my source code.
